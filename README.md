    PROJETO CONVERSOR DE MOEDAS

Este é um projeto simples que faz a conversão de moedas Real, Dólar, Euro, etc. O qual desenvolvi para praticar lógica de progrmação, entrada de dados, operações matemáticas e boas práticas com a linguagem Python.

Funcionalidades:

- Conversão de BRL para USD, EUR, GBP e outras moedas.
- Interface via terminal (linha de comando).
- Fácil de expandir com uso de APIs (ex: taxas de câmbio em tempo real).
